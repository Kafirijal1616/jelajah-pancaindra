PANDUAN MENGHUBUNGKAN POP-UP PENGUNJUNG JELAJAH PANCAINDRA KE GOOGLE SHEETS APA YANG AKAN TERJADI? - Saat website pertama kali dibuka, pop-up meminta Nama, Kelas, dan Sekolah. - Permainan belum bisa dilanjutkan sampai data dikirim dan Apps Script mengonfirmasi penyimpanan. - Setiap pengiriman dicatat sebagai satu kunjungan pada tab Pengunjung. - Tab Rekap menghitung otomatis jumlah pengiriman, identitas gabungan, jumlah sekolah, jumlah kelas, kunjungan per sekolah, per kelas, serta kombinasi sekolah dan kelas. - Ini menghitung pengiriman buku tamu, bukan identitas unik yang terverifikasi. Orang yang mengisi ulang dapat tercatat lagi. LANGKAH 1 — BUAT GOOGLE SHEETS 1. Buka https://sheets.google.com dan buat spreadsheet kosong. 2. Beri nama: Daftar Pengunjung Jelajah Pancaindra. 3. Salin ID spreadsheet dari alamat URL. Contoh: https://docs.google.com/spreadsheets/d/INI_ID_SPREADSHEET/edit Bagian INI_ID_SPREADSHEET adalah ID yang diperlukan. LANGKAH 2 — BUAT APPS SCRIPT 1. Dari spreadsheet, pilih Extensions / Ekstensi > Apps Script. 2. Buka file Code.gs yang ada di folder paket ini. 3. Salin seluruh isi Code.gs ke editor Apps Script, menggantikan contoh kode yang ada. 4. Ganti nilai GANTI_DENGAN_ID_GOOGLE_SHEETS dengan ID spreadsheet milik Anda. Jangan hapus tanda petik. 5. Klik Save / Simpan. 6. Di daftar fungsi bagian atas, pilih setupVisitorWorkbook lalu klik Run / Jalankan. 7. Ikuti layar izin Google dan izinkan skrip mengelola spreadsheet yang Anda buat. Jalankan sekali saja. Spreadsheet akan mempunyai tab Pengunjung dan Rekap. LANGKAH 3 — DEPLOY SEBAGAI WEB APP 1. Di Apps Script klik Deploy > New deployment. 2. Klik ikon pengaturan jenis deployment, lalu pilih Web app. 3. Execute as / Jalankan sebagai: Me / Saya. 4. Who has access / Siapa yang memiliki akses: Anyone / Siapa saja, agar pengunjung website yang tidak login Google bisa mengirim buku tamu. 5. Klik Deploy dan selesaikan otorisasi jika diminta. 6. Salin URL Web app yang berakhiran /exec. Jangan gunakan URL uji yang berakhiran /dev. Catatan: beberapa akun sekolah/organisasi membatasi akses Anyone. Jika opsi itu tidak tersedia, mintalah admin domain mengatur izin, atau gunakan akun Google pribadi yang diizinkan. LANGKAH 4 — MASUKKAN URL KE HTML 1. Buka index.html menggunakan editor teks seperti Notepad atau VS Code. 2. Cari teks persis: var VISITOR_WEB_APP_URL='https://script.google.com/macros/s/AKfycbwCvTAzdNzi2S9JQaTmcww-r80aJWni0Abl_qaVBr1kOM3BSIkWKbz9v7BI6qQKFovZ/exec'; 3. Ganti PASTE_WEB_APP_URL_HERE dengan URL /exec yang Anda salin. Contoh bentuknya: var VISITOR_WEB_APP_URL='https://script.google.com/macros/s/ID_DEPLOYMENT_ANDA/exec'; Gunakan URL Anda sendiri, bukan contoh ini. 4. Simpan file. 5. Unggah index.html yang baru ke repository GitHub Anda dan pilih Commit changes. 6. Buka website GitHub Pages, isi formulir uji, kirim, lalu periksa tab Pengunjung dan Rekap di spreadsheet. CARA MEMBACA REKAP - Total kunjungan: jumlah semua pengiriman buku tamu. - Identitas gabungan unik: perkiraan jumlah kombinasi Nama + Kelas + Sekolah yang berbeda. Ini bukan verifikasi identitas orang. - Jumlah sekolah dan kelas: banyaknya nilai yang berbeda di kolom tersebut. - Ringkasan berdasarkan sekolah/kelas: jumlah pengiriman per kelompok. Rumus akan menghitung ulang saat baris Pengunjung bertambah. CARA MEMPERBARUI KODE APPS SCRIPT Jika Anda mengubah Code.gs setelah deploy, buka Deploy > Manage deployments > Edit (ikon pensil), pilih New version jika diminta, lalu Deploy agar versi produksi ikut berubah. URL /exec dapat tetap sama saat deployment yang sama diperbarui. PRIVASI DAN BATASAN - Beri tahu pengunjung bahwa Nama/Kelas/Sekolah dikirim ke spreadsheet yang dikelola pembuat media. Jangan membuat spreadsheet publik. - Karena pengunjung mungkin anak-anak, mintalah persetujuan guru/orang tua atau pihak sekolah sesuai kebutuhan. Pertimbangkan nama panggilan bila nama lengkap tidak diperlukan. - Jangan meminta alamat rumah, nomor telepon, password, NISN, atau informasi sensitif untuk sekadar rekap kunjungan. - Data hanya tercatat jika formulir dikirim. Orang yang menutup website sebelum mengirim tidak masuk ke daftar. - Endpoint Web App publik dapat disalahgunakan. Kode memiliki validasi dasar dan kolom jebakan antispam, tetapi ini bukan sistem identitas yang terverifikasi atau perlindungan antispam tingkat lanjut.
